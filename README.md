## Key Features & Design Philosophy

* **Modern Dark-Mode Glassmorphism:** Styled in deep obsidian (`#050505`) with translucent glass panels, `backdrop-filter: blur(28px)`, ambient radial gradients, and subtle hovering drop-shadows.
* **Pure Static Performance:** Zero runtime dependencies or heavy JavaScript frameworks. Blazing-fast initial load times, zero Flash of Unstyled Content (FOUC), and 100% crawlable semantic HTML for search engines and Google Scholar.
* **Custom Hydrodynamic Branding:** Includes a custom waving-water vector logo (`assets/water_m_logo.svg`) evocative of Sentinel-1 SAR surface-water segmentation research, used as both the site favicon and header brand icon.
* **Complete Social Graph & SEO:** Pre-configured with Open Graph (`og:*`) and Twitter Card (`twitter:*`) metadata for rich social previews on LinkedIn, Twitter/X, and WhatsApp, alongside clean `sitemap.xml` and `robots.txt` files.
* **Mobile-First & Accessible:** Fully responsive across mobile, tablet, and desktop viewports, featuring an accessible slide-out navigation menu and scroll-reveal micro-interactions powered by `IntersectionObserver`.

## Local Development & Preview

Because this is a pure static website, no complex build steps, package managers, or compilers are required.

To preview the website locally on your computer:

### Option 1: Python HTTP Server (Recommended)
```bash
# Clone the repository
git clone https://github.com/imusshas/imusshas.github.io.git
cd imusshas.github.io

# Start a local static server
python3 -m http.server 8000
```
Open your browser and navigate to `http://localhost:8000`.

### Option 2: Node.js `serve` / `npx`
```bash
npx serve .
```

## Deployment to GitHub Pages

1. Push all files to the `main` branch of your repository named `imusshas.github.io`.
2. Go to repository **Settings** → **Pages**.
3. Under **Build and deployment** → **Source**, select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)` folder, then click **Save**.
5. Your portfolio will automatically deploy to `https://imusshas.github.io/`.
